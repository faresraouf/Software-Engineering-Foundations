# 03 - Programming Using C++ Level 1

## Overview
A foundation course covering core **C++** programming concepts followed by practical homework exercises drawn from the **Algorithms & Problem-Solving** series from Course 02. This structure connects the manual flowchart logic developed earlier with real, compiled C++ implementations.

> **Note:** Previous local solution files were removed, so the `.cpp` practice files and algorithm homework solutions are being rebuilt progressively in batches.

## Core Concepts & Homework Approach
* **Concept-to-Homework Workflow:** Each C++ topic is paired with algorithm problems from Course 02 as homework assignments, translating previously traced flowchart logic into clean, modular C++ code.
* **Program Structure & I/O:** Standard headers (`<iostream>`), `main()`, console output (`std::cout`), and user input (`std::cin`).
* **Variables & Data Types:** Primitive types (`int`, `float`, `double`, `char`, `bool`, `string`) and type handling.
* **Operators & Expressions:** Arithmetic, assignment, relational, and logical operators with operator precedence.
* **Control Flow:** Conditional branching (`if`, `else if`, `else`, `switch`) and loops (`for`, `while`, `do-while`).
* **Functions & Modularity:** Breaking problems into focused, single-responsibility functions, parameters, and scope.
* **Arrays, Structs & Enums:** Organizing related data, collections, and grouped states cleanly.
